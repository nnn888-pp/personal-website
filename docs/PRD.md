# 个人作品集网站 · 产品需求文档（PRD）

> 版本：v1.0　日期：2026-10-28　作者：小萍

## 1. 项目概述

| 项 | 内容 |
|---|---|
| 项目名称 | 纸间集 · 个人作品集网站（名称可改） |
| 项目定位 | 单页滚动式个人作品集，展示 AI 全栈课程学习成果 |
| 目标用户 | 课程评审老师、潜在雇主、同行开发者 |
| 核心价值 | 访客打开 30 秒内了解「我是谁、会什么、做过什么」 |

## 2. 项目目标

- 完成课程作业交付：PRD + 技术设计文档 + AGENTS.md 三份文档，网站样式个性化，成功部署上线
- 长期价值：作为个人作品集持续更新，沉淀项目成果

## 3. 功能需求

### P0 核心功能（本次必须完成）

| 编号 | 功能 | 说明 |
|---|---|---|
| F1 | 首页 Hero 区 | 昵称 + 一句话 Slogan + 杂志风主视觉排版 |
| F2 | 关于我 | 个人简介（100~150 字）+ 技能标签组 |
| F3 | 作品集 | 卡片式项目列表：项目图/标题/简介/技术栈/链接，至少 4 个项目（详见第 5 节） |
| F4 | 学习经历时间线 | 竖向时间线，展示学习/实践经历 |
| F5 | 页脚联系区 | 邮箱、GitHub 链接 |
| F6 | 响应式布局 | PC 与手机端均正常显示 |
| F7 | 固定导航栏 | 顶部导航 + 锚点平滑滚动到对应板块 |

### P1 增强功能（时间允许再做）

- 滚动进入时的淡入动画
- 返回顶部按钮
- 项目卡片悬停效果

### 明确不做（控制范围）

- 无后端、无数据库、无登录注册
- 无博客文章系统、无评论功能
- 无第三方统计/埋点、无多语言

## 4. 内容规划

### 作品集项目清单

1. **AI 大模型预训练与微调实操** — 自有 Tokenizer + Transformer 自回归预训练、监督微调、LoRA 低秩微调
2. **电商图片下载浏览器插件** — 图片批量抓取插件，含独立官网与 GitHub Pages 发布
3. **零代码平台应用** — 纯前端 localStorage 单页应用
4. **本网站本身** — 从 PRD 到部署的 AI 辅助开发全流程实践（Vue 3 + Vite）

## 5. 设计规范（复古杂志风）

| 项 | 规范 |
|---|---|
| 主背景 | 米白纸感底色（如 #F7F2E9），可叠加极浅纸张纹理 |
| 正文色 | 墨色深棕黑（如 #2B2620） |
| 强调色 | 朱砂红（如 #A8402E），用于标题点缀、编号、标签 |
| 辅助色 | 赭石灰（如 #8A7E6D），用于次要文字、分隔线 |
| 标题字体 | 衬线宋体（Noto Serif SC / 思源宋体），大号粗排 |
| 正文字体 | 宋体或细黑，行高宽松（1.8 左右） |
| 版式元素 | 杂志式网格分栏、板块编号（01 / 02 / 03）、细双分隔线、竖排装饰字、印章感徽章点缀 |
| 整体气质 | 像一本排版讲究的纸质杂志，克制、留白多、不堆砌特效 |

## 6. 页面结构（单页自上而下）

固定导航栏 → Hero 区 → 关于我（01） → 作品集（02） → 经历时间线（03） → 联系页脚

## 7. 非功能需求

- 纯前端实现，技术栈 Vue 3 + Vite，部署到 Cloudflare Pages，**国内可直接访问**
- 首屏加载 < 3 秒，图片压缩处理
- 兼容 Chrome / Edge 最新版，手机端布局不错乱

## 8. 验收标准

- [x] 无痕窗口打开部署域名可正常访问（personal-website-are.pages.dev）
- [x] 五大板块内容完整，无占位文字残留
- [x] 样式与课程示例明显不同，体现复古杂志风个性化设计
- [x] 手机端（375px 宽度）无横向滚动、无文字溢出
- [x] 技术栈非纯 HTML，采用 Vue 3 + Vite 工程化实现
