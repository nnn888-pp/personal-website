# 个人作品集网站 · 技术设计文档

> 版本：v1.0　日期：2026-10-28　对应 PRD：v1.0

## 1. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 前端框架 | Vue 3（组合式 API） | 组件化开发，单文件组件，数据驱动视图 |
| 构建工具 | Vite | 极速冷启动，原生 ESM，构建产物优化 |
| 路由 | Vue Router 4 | 单页应用路由，管理首页与管理后台 |
| HTTP 客户端 | Axios | 封装 API 请求，统一鉴权头 |
| 样式 | 原生 CSS3（CSS 变量管理主题色） | 无需框架，加载快，复古排版用原生 CSS 足够 |
| 后端框架 | Node.js + Express | 轻量、上手快，提供 RESTful API |
| 数据库 | MySQL | 关系型数据库，用 Navicat 可视化管理 |
| 数据库驱动 | mysql2 | Promise 风格，支持连接池 |
| 字体 | Google Fonts：Noto Serif SC（思源宋体） | 复古杂志风核心，CDN 引入 |
| 前端部署 | Cloudflare Pages | 国内访问快，免费，自动分配域名 |
| 后端部署 | 本地 / Railway / Render | Node.js 服务托管 |

**技术栈特征**：前后端分离，Vue 3 单页应用 + Node.js/Express 后端 + MySQL 数据库，支持管理后台在线编辑网站内容。

## 3. 页面技术方案

### 3.1 布局
- CSS Grid + Flexbox 实现杂志式网格；`max-width: 1080px` 居中容器
- 响应式断点：`768px`（手机单列，PC 多栏）
- 板块编号用大字衬线排版（01 / 02 / 03），作为视觉锚点
- 单页应用：所有板块在一个页面内，通过锚点平滑滚动跳转

### 3.2 复古杂志风实现要点

| 效果 | 实现方式 |
|---|---|
| 纸感背景 | CSS 变量底色 `#F7F2E9` + 极低透明度噪点 SVG 背景 |
| 衬线大标题 | Noto Serif SC，字重 700/900，字距微调 |
| 分隔线 | `border-top: 1px solid` 与双细线（`double`）混用 |
| 竖排装饰字 | `writing-mode: vertical-rl` |
| 印章徽章 | 朱砂红底 + 白色宋体字，微旋转（`transform: rotate(-4deg)`） |
| 滚动淡入 | IntersectionObserver 添加 `.visible` 类，CSS transition 透明度+位移 |
| 平滑滚动 | `scroll-behavior: smooth` + 锚点 `scroll-margin-top` 避让固定导航 |

### 3.3 主题色 CSS 变量（初值，可调）

```css
:root {
  --paper: #F7F2E9;      /* 纸底 */
  --ink: #2B2620;        /* 墨色 */
  --cinnabar: #A8402E;   /* 朱砂强调 */
  --ochre: #8A7E6D;      /* 赭石灰 */
  --hairline: #D8CFBF;   /* 分隔线 */
}
```

## 4. 关键技术点

1. **组件化拆分**：每个板块独立为一个 Vue 单文件组件（`.vue`），根组件 `App.vue` 通过路由渲染页面
2. **数据驱动视图**：作品集卡片、时间线条目用数组 + `v-for` 渲染，数据从后端 API 获取
3. **前后端分离**：前端通过 axios 调用后端 RESTful API，后端操作 MySQL 数据库
4. **管理后台**：`/admin` 路由，密码登录后可在线编辑所有内容（个人信息、标签、作品、经历）
5. **简单鉴权**：管理密码存后端 `.env`，前端登录后存 localStorage，请求时携带 `x-admin-password` 头
6. **固定导航 + 锚点跳转**：导航 `position: fixed`，锚点目标设 `scroll-margin-top: 72px` 防止被遮挡
7. **构建流程**：前端 `npm run build` → `dist/` 部署 Cloudflare Pages；后端 `npm start` 部署 Node.js 服务

## 5. 部署方案

### 前端（Cloudflare Pages）
1. 本地执行 `npm run build`，确认 `dist/` 产出正常
2. 代码推送至 GitHub 仓库
3. Cloudflare Pages → 创建应用 → 导入 GitHub 仓库
4. 构建配置：框架预设选 **Vue**，构建命令 `npm run build`，输出目录 `dist`
5. 部署后复制 `xxx.pages.dev` 域名

### 后端（Node.js 服务）
- **本地开发**：`cd server && npm install && npm start`，服务运行在 `http://localhost:3001`
- **生产部署**：可部署到 Railway、Render、Fly.io 或云服务器
- **环境变量**：需配置 `DB_HOST`、`DB_USER`、`DB_PASSWORD`、`DB_NAME`、`ADMIN_PASSWORD`

### 数据库（MySQL）
1. 本地安装 MySQL，用 Navicat 连接
2. 执行 `server/sql/init.sql` 创建数据库和表
3. 生产环境使用云数据库（阿里云/腾讯云/Railway MySQL 等）
