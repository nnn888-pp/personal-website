# 个人作品集网站 · 技术设计文档

> 版本：v1.0　日期：2026-10-28　对应 PRD：v1.0

## 1. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 前端框架 | Vue 3（组合式 API） | 组件化开发，单文件组件，数据驱动视图 |
| 构建工具 | Vite | 极速冷启动，原生 ESM，构建产物优化 |
| 样式 | 原生 CSS3（CSS 变量管理主题色） | 无需框架，加载快，复古排版用原生 CSS 足够 |
| 字体 | Google Fonts：Noto Serif SC（思源宋体） | 复古杂志风核心，CDN 引入 |
| 部署 | Cloudflare Pages | 国内访问快，免费，自动分配域名 |

**技术栈特征**：Vue 3 单页应用（SPA），组件化拆分，Vite 构建产出静态文件，无后端、无数据库。

## 3. 页面技术方案

### 3.1 布局
- CSS Grid + Flexbox 实现杂志式网格；`max-width: 1080px` 居中容器
- 响应式断点：`768px`（手机单列，PC 多栏）
- 板块编号用大字衬线排版（01 / 02 / 03），作为视觉锚点
- 单页应用：所有板块在一个页面内，通过锚点平滑滚动跳转

### 3.2 复古杂志风实现要点

| 效果 | 实现方式 |
|---|---|
| 纸感背景 | CSS 变量底色 `#F7F2E9` + 极低透明度噪点 SVG 背景 |
| 衬线大标题 | Noto Serif SC，字重 700/900，字距微调 |
| 分隔线 | `border-top: 1px solid` 与双细线（`double`）混用 |
| 竖排装饰字 | `writing-mode: vertical-rl` |
| 印章徽章 | 朱砂红底 + 白色宋体字，微旋转（`transform: rotate(-4deg)`） |
| 滚动淡入 | IntersectionObserver 添加 `.visible` 类，CSS transition 透明度+位移 |
| 平滑滚动 | `scroll-behavior: smooth` + 锚点 `scroll-margin-top` 避让固定导航 |

### 3.3 主题色 CSS 变量（初值，可调）

```css
:root {
  --paper: #F7F2E9;      /* 纸底 */
  --ink: #2B2620;        /* 墨色 */
  --cinnabar: #A8402E;   /* 朱砂强调 */
  --ochre: #8A7E6D;      /* 赭石灰 */
  --hairline: #D8CFBF;   /* 分隔线 */
}
```

## 4. 关键技术点

1. **组件化拆分**：每个板块独立为一个 Vue 单文件组件（`.vue`），根组件 `App.vue` 负责装配，职责清晰
2. **数据驱动视图**：作品集卡片、时间线条目用数组 + `v-for` 渲染，新增内容只需改数据
3. **固定导航 + 锚点跳转**：导航 `position: fixed`，锚点目标设 `scroll-margin-top: 72px` 防止被遮挡
4. **作品卡片**：Grid 两列（手机一列），卡片内含项目图、标题、简介、技术栈标签
5. **时间线**：左侧竖线 + 圆点节点，用 `::before` 伪元素绘制
6. **构建流程**：`npm run build` → Vite 产出 `dist/` 静态文件 → 部署到 Cloudflare Pages

## 5. 部署方案

1. 本地执行 `npm run build`，确认 `dist/` 产出正常
2. 代码推送至 GitHub 仓库
3. Cloudflare Pages → 创建应用 → 导入 GitHub 仓库
4. 构建配置：框架预设选 **Vue**，构建命令 `npm run build`，输出目录 `dist`
5. 部署后复制 `xxx.pages.dev` 域名，**无痕窗口验证可访问**后填入作业表单

## 6. 测试要点

- 无痕窗口访问部署域名，五大板块显示完整
- F12 切 375px 设备模式检查无横向滚动
- 控制台无报错，无 404 资源
