# 个人作品集网站 · 技术设计文档

> 版本：v1.0　日期：2026-10-28　对应 PRD：v1.0

## 1. 技术选型

| 层 | 选型 | 理由 |
|---|---|---|
| 页面结构 | 纯 HTML5（单页 index.html） | 无后端需求，静态页最简单可靠 |
| 样式 | 原生 CSS3（CSS 变量管理主题色） | 无需框架，加载快，复古排版用原生 CSS 足够 |
| 交互 | 原生 JavaScript（少量） | 仅需平滑滚动、滚动淡入、返回顶部 |
| 字体 | Google Fonts：Noto Serif SC（思源宋体） | 复古杂志风核心，CDN 引入 |
| 图标 | 内联 SVG | 无外部依赖，可精细控制 |
| 部署 | Cloudflare Pages | 国内访问快，免费，自动分配域名 |

**明确不用**：React/Vue 等框架、构建工具、后端服务、数据库——单页静态站用不上，避免过度工程。

## 2. 项目结构

```
个人网站/
├── docs/                  # 文档（PRD、技术设计）
├── AGENTS.md              # AI 开发规范
└── site/                  # 网站源码（部署此目录）
    ├── index.html         # 唯一页面
    ├── css/
    │   └── style.css      # 全部样式
    ├── js/
    │   └── main.js        # 交互脚本
    └── assets/            # 图片、纹理、项目截图
```

## 3. 页面技术方案

### 3.1 布局
- CSS Grid + Flexbox 实现杂志式网格；`max-width: 1080px` 居中容器
- 响应式断点：`768px`（手机单列，PC 多栏）
- 板块编号用大字衬线排版（01 / 02 / 03），作为视觉锚点

### 3.2 复古杂志风实现要点

| 效果 | 实现方式 |
|---|---|
| 纸感背景 | CSS 变量底色 `#F7F2E9` + 极低透明度噪点 SVG 背景 |
| 衬线大标题 | Noto Serif SC，字重 700/900，字距微调 |
| 分隔线 | `border-top: 1px solid` 与双细线（`double`）混用 |
| 竖排装饰字 | `writing-mode: vertical-rl` |
| 印章徽章 | 朱砂红底 + 白色宋体字，微旋转（`transform: rotate(-4deg)`） |
| 滚动淡入 | IntersectionObserver 添加 `.visible` 类，CSS transition 透明度+位移 |
| 平滑滚动 | `scroll-behavior: smooth` + 锚点 `scroll-margin-top` 避让固定导航 |

### 3.3 主题色 CSS 变量（初值，可调）

```css
:root {
  --paper: #F7F2E9;      /* 纸底 */
  --ink: #2B2620;        /* 墨色 */
  --cinnabar: #A8402E;   /* 朱砂强调 */
  --ochre: #8A7E6D;      /* 赭石灰 */
  --hairline: #D8CFBF;   /* 分隔线 */
}
```

## 4. 关键技术点

1. **固定导航 + 锚点跳转**：导航 `position: fixed`，锚点目标设 `scroll-margin-top: 72px` 防止被遮挡
2. **作品卡片**：Grid 两列（手机一列），卡片内含项目图（16:10 裁切）、标题、简介、技术栈标签、链接
3. **时间线**：左侧竖线 + 圆点节点，用 `::before` 伪元素绘制
4. **图片策略**：项目截图统一压缩为宽度 ≤1200px 的 JPG/WebP，放 `assets/`

## 5. 部署方案

1. 代码推送至 GitHub 仓库（如 `personal-website`）
2. Cloudflare Pages → 创建应用 → 导入 GitHub 仓库
3. 构建配置：无需构建命令，输出目录填 `site`
4. 部署后复制 `xxx.pages.dev` 域名，**无痕窗口验证可访问**后填入作业表单

## 6. 测试要点

- 无痕窗口访问部署域名，五大板块显示完整
- F12 切 375px 设备模式检查无横向滚动
- 控制台无报错，无 404 资源
